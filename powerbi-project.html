How it is built

Source CSVs land in a raw layer that never rejects a row, are decoded and typed in staging, and are modelled into a star schema in a mart. Each layer is a separate Oracle user, so the boundary between them is enforced by the database rather than by naming convention — the account Power BI connects with holds a read role and no quota, and physically cannot write to the mart.
